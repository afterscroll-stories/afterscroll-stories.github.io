Privacy Policy

Last updated: November 8, 2026

1. Overview

AfterScroll Automation is a private automation project used exclusively by its operator. It is not offered as a public service.

2. Google User Data

The application uses Google OAuth and the YouTube Data API to upload videos to the operator's own YouTube channel. This includes video files, titles, descriptions and hashtags.

3. Storage and Processing

OAuth credentials are stored in the self-hosted n8n credential storage. Video files and metadata are processed locally using the operator's automation environment.

4. Sharing of Information

Google user data is not sold or used for advertising. Information is transmitted to Google only as necessary to perform the requested YouTube upload operations.

5. Data Security

Access to the automation environment is restricted to its operator. Reasonable measures are taken to protect stored credentials and data.

6. Contact

For privacy-related questions, contact the operator using the contact information provided on the associated GitHub profile.
